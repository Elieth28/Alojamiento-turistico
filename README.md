 PAZ Y WTRANQUILIDAD 🌿

Landing page de alojamientos turísticos desarrollada como actividad evaluada del curso de Desarrollo Frontend.

## 🔗 Sitio publicado
https://tu-usuario.github.io/refugio-verde-alojamientos/

## 📋 Descripción
Página web de una sola página con temática de alojamientos turísticos en la naturaleza.

## 🗂️ Estructura del proyecto
- `index.html` — Estructura principal de la página
- `styles.css` — Estilos y diseño responsive
- `script.js` — Validación del formulario e interacciones

## 📌 Secciones
1. Hero — imagen, título y CTA
2. Navbar — fijo con menú hamburguesa
3. Nosotros — descripción del negocio
4. Servicios — tarjetas con CSS Grid
5. Formulario — validación con JavaScript
6. Footer — redes, año dinámico y créditos

## 🛠️ Tecnologías
- HTML5
- CSS3 (Grid, Flexbox, animaciones)
- JavaScript (DOM, validación, IntersectionObserver)
